# Apple Catcher Game 🐰🍎
A simple Python console game where the player moves around a 10x10 board and collects apples to increase the score.
# Features
Move using W, A, S, D                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    
Multiple character choices
Score tracking
Auto-play mode
Random apple spawning
# How to Run
python main.py
# Controls
Key	Action
W	Move Up
S	Move Down
A	Move Left
D	Move Right
auto	Automatic gameplay
t	Exit current game
